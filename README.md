# CLASS Enter

東京理科大学 CLASS の入口画面で「ENTER」を自動クリックして進む Brave／Chrome 用拡張機能です。入口で Enter キーを押す操作は不要です。手動の Enter 操作にも対応します。

出席登録画面では認証コードを入力して Enter を押してください。コード入力欄にカーソルがある状態でも登録できます。登録の成否や入力チェックはサイトが判定します。確認ダイアログが出る場合はサイトの案内に従ってください。

## 認証コードの全角数字を半角に補正する

バージョン **1.4.0 以降**では、認証コード画面で全角数字を入力すると、自動で半角数字に変換します。例：`６３３６` → `6336`。貼り付けにも対応し、IME 変換中は変更せず、文字の確定後に補正します。数字以外の文字は変更・削除しません。

補正は「認証コード」と「出席登録する」がある入力フォームを対象とし、フォームがある場合は登録ボタンと同じフォームのテキスト・電話番号・数値入力欄で動作します。入口の自動／手動設定に関係なく有効です。出席登録のクリックや Enter 操作の直前にも補正します。認証コードの保存や外部送信は行いません。

## Backspace で認証コードを修正する

バージョン **1.5.0 以降**では、独立した4つの認証コード欄を Backspace で戻りながら修正できます。

- 数字が入っている欄：通常どおり、その欄の数字を削除します。
- 空の欄：ひとつ前の欄へ移動し、そこの数字を削除します。続けて Backspace を押すと、さらに前の欄を修正できます。
- 最初の欄：それより前へは移動しません。

同じフォーム内に表示・編集可能な認証コード欄が4つあり、それぞれ空または数字1文字の場合に補助します。IME 変換中や修飾キー付きの Backspace には介入しません。入口の自動／手動設定に関係なく有効で、出席登録は Enter または登録ボタンで行います。

## 自動／手動の切り替え

1. ブラウザ右上のパズルピースのアイコン（拡張機能）をクリックします。
2. 一覧から「CLASS Enter」をクリックして設定画面を開きます。
3. 「入口を自動で進む」のチェックを切り替えます。
   - チェックあり（オン）：入口の「ENTER」を自動クリックして進みます。
   - チェックなし（オフ）：Enter キーを押すか、「ENTER」ボタンをクリックして進みます。
4. CLASS のページを再読み込みすると、変更が反映されます。

初期設定はオンです。設定はブラウザ内に保存され、次回も維持されます。出席登録はどちらの設定でもコード入力後の Enter 操作で実行します。

### 「C」アイコンをツールバーに表示する

アイコンを固定すると、次回から直接設定を開けます。

- Brave：`brave://extensions` →「CLASS Enter」の「詳細」→「ツールバーに固定する」をオンにします。
- Chrome：ブラウザ右上の拡張機能メニューで「CLASS Enter」のピンアイコンをクリックします。

ブラウザ右上に表示された「C」アイコンをクリックすると、自動／手動の設定画面が開きます。

### 設定が見つからない場合

拡張機能の詳細画面にある「オン」は、拡張機能全体を有効／無効にするスイッチです。自動／手動を切り替える場合は、拡張機能メニューの「CLASS Enter」、ツールバーの「C」アイコン、または以下の「拡張機能のオプション」から設定を開いてください。「サイトへのアクセス」は動作を許可する設定なので、自動／手動の切り替えには使いません。

設定画面が表示されない場合は、以下の更新手順を確認してください。自動／手動の切り替えはバージョン **1.3.0 以降**に対応しています。

### 拡張機能の「詳細」から変更する

バージョン **1.3.1 以降**では、ツールバーにアイコンを固定せずに設定を開けます。

1. `brave://extensions` または `chrome://extensions` を開きます。
2. 「CLASS Enter」の「詳細」をクリックします。
3. 「拡張機能のオプション」をクリックします。
4. 開いた設定画面で「入口を自動で進む」のチェックを切り替えます。
5. CLASS のページを再読み込みします。

アイコンから開く設定と同じ値が保存されます。「拡張機能のオプション」が見つからない場合は、最新版に更新して拡張機能を再読み込みしてください。

## インストール

1. このリポジトリをダウンロードし、ZIP の場合は展開します。
2. Brave の `brave://extensions` または Chrome の `chrome://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` が入ったフォルダを選びます。
5. CLASS のページを再読み込みすると、入口画面から自動で進みます。

## インストール済みの拡張機能を更新する

1. GitHub の「Code」→「Download ZIP」から最新版をダウンロードして解凍します。
2. 解凍したファイルを、現在読み込んでいるフォルダのファイルと置き換えます。新しいフォルダを使う場合は、古い拡張機能を削除してから、新しいフォルダを「パッケージ化されていない拡張機能を読み込む」で選びます。
3. `brave://extensions` または `chrome://extensions` で、CLASS Enter の再読み込みボタン（丸い矢印）を押します。
4. 詳細画面でバージョンを確認します。
5. CLASS のページも再読み込みします。

読み込むフォルダには `manifest.json`、`content.js`、`popup.html`、`popup.css`、`popup.js` が必要です。ZIP にフォルダが入っている場合は、`manifest.json` が直接入っているフォルダを選んでください。現在の読み込み先は、拡張機能の詳細画面の「ソース」／「ロード元」で確認できます。

## 動作範囲

- `https://class.admin.tus.ac.jp/` 配下のみで動作します。
- 自動クリックは「ENTER」だけが対象で、ページごとに一度だけ実行します。ボタンの遅延表示は最大15秒待ちます。出席登録は認証コード入力後の Enter 操作で実行します。
- 表示中かつ有効な対象ボタン／リンクがちょうど一つある場合だけクリックします。画像ボタンの代替テキストにも対応します。「再表示する」はクリックしません。
- 認証コード画面のテキスト・電話番号・数値入力欄では Enter による出席登録に対応します。フォームがある場合、同じフォームの登録ボタンだけが対象です。
- その他の入力欄、編集中の領域、フォーカス中のリンク／ボタン、IME 変換中、長押し、修飾キー付きの Enter は処理しません。
- 設定保存のための `storage` 権限を使用します。ログイン情報の保存・送信や、自動ログインは行いません。外部通信・ビルドは不要です。

## 開発と検証

Node.js 18 以降で `node --test tests/*.test.cjs` を実行します。外部依存はありません。
変更後は拡張機能の管理画面で拡張機能を再読み込みし、CLASS のページも再読み込みしてください。

実サイトの HTML はクラウド環境のネットワーク制限で取得できていないため、スクリーンショットを元にボタンの表示文字を判定しています。実サイトでの最終動作確認が必要です。ボタンが文字・代替テキストを持たない場合には、HTML に合わせた調整が必要です。
