# CLASS Enter

東京理科大学 CLASS の入口画面で、キーボードの **Enter** を押すと「ENTER」ボタンをクリックする Brave／Chrome 用拡張機能です。

## インストール

1. このリポジトリをダウンロードし、ZIP の場合は展開します。
2. Brave の `brave://extensions` または Chrome の `chrome://extensions` を開きます。
3. 「デベロッパーモード」を有効にします。
4. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` が入ったフォルダを選びます。
5. CLASS のページを再読み込みし、入口画面で Enter キーを押します。

## 動作範囲

- `https://class.admin.tus.ac.jp/` 配下のみで動作します。
- 表示中かつ有効な「ENTER」ボタン／リンクがちょうど一つある場合だけクリックします。画像ボタンの代替テキストにも対応します。
- 入力欄、編集中の領域、フォーカス中のリンク／ボタン、IME 変換中、長押し、修飾キー付きの Enter は処理しません。
- ログイン情報の保存・送信や、自動ログインは行いません。追加の権限・外部通信・ビルドは不要です。

## 開発と検証

Node.js 18 以降で `node --test tests/content.test.cjs` を実行します。外部依存はありません。
変更後は拡張機能の管理画面で拡張機能を再読み込みし、CLASS のページも再読み込みしてください。

実サイトの HTML はクラウド環境のネットワーク制限で取得できていないため、スクリーンショットを元にボタンの表示文字を判定しています。実サイトでの最終動作確認が必要です。ボタンが文字・代替テキストを持たない場合には、HTML に合わせた調整が必要です。
